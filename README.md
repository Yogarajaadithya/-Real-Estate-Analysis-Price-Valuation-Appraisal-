# Real Estate Analysis & Price Valuation Appraisal

This repository contains data science workflows for analyzing the Zillow housing dataset.  
It includes:
- Data preprocessing and sampling (e.g., stratified samples).
- Exploratory data analysis with R for price valuation and appraisal.
- Geolocation querying using Python.

## Data
- Raw and processed property datasets (CSV files) are stored under `/data`.

## Code
- R scripts and Quarto reports for data wrangling, analysis, and visualization.
- A Python script to find nearby amenities based on a given location.
